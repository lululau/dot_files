## 操作步骤

1. **理解用户需求**：根据上面的参数说明（或用户回答），理解用户想要保存什么内容

2. **确定条目信息**：
   - **标题**: 根据内容生成一个简洁明了的标题
   - **标签**：根据内容从以下标签中选择一个或多个（用冒号分隔）：
     - `learn` - 学习笔记
     - `artifact` - 产出物/代码
     - `util` - 实用工具/技巧
     - `work` - 工作相关

3. **生成时间戳**：使用当前时间生成 HH:MM 格式的时间戳

4. **保存到 org-journal**：
   - 目标目录：`/Users/liuxiang/Documents/materials/journal`
   - 文件名格式：`YYYY-MM-DD`（使用当天日期，如 `2025-12-30`，不带 `.org` 后缀名）
   - 追加或创建文件，写入 org-mode 格式的条目

5. **确认结果**：告诉用户条目已保存，并提供文件路径

## Org Entry 格式

```org
** DONE HH:MM 标题   :tags:

内容正文

可以包含多个段落或列表

- 要点1
- 要点2
```

应该是用 org-mode 格式编写：

1. `** DONE HH:MM 标题   :tags:`：行是二级标题，也是所有保存内容的父节点，也就是保存内容中的除此之外最大标题层级是三级标题
1. 对于技术名词、代码中的名称等要用 =code font= 包围
2. 对于代码示例，使用 org-mode 的代码块语法: #+BEGIN_SRC language ... #+END_SRC


### 示例

```org
** DONE 14:32 学习 Rust 所有权   :learn:

今天学习了 Rust 的所有权系统，核心概念：
- 每个值都有一个所有者
- 同一时间只能有一个所有者
- 所有者离开作用域时值被丢弃

相关代码示例需要在 let 声明时明确类型。
```

## 注意事项

- 文件名使用当天日期, 当天日期使用 `date` 命令获取
- 时间戳格式为 `HH:MM`（24小时制）, 使用 `date +%H:%M` 获取
- 标签以冒号包围，多个标签连续写，如 `:learn:artifact:`
- `** DONE` 表示已完成状态（也可用 `** TODO` 表示未完成）
- 保留代码的原始格式
- 如果文件已存在，直接追加内容
