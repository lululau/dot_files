# Save to Obsidian

请将当前对话中的一些内容保存到 Obsidian 笔记中。

{{- if .Args }}
用户指定要保存的内容：{{ .Args }}

{{- else }}
用户未指定要保存的具体内容。请询问用户想要保存当前对话中的哪部分内容，例如：
- 最近的代码讨论
- 某个技术问题的解决方案
- 任务列表
- 重要的结论或决策

请根据用户的回答，提取对话中的相关内容并保存到 Obsidian。
{{- end }}

## 操作步骤

1. **理解用户需求**：根据上面的参数说明（或用户回答），理解用户想要保存什么内容

2. **提取内容**：从当前对话历史中提取相关的核心内容，包括：
   - 代码片段（如果有）
   - 重要的结论或决策
   - 问题解决方案
   - 任务清单（如有）

3. **确定笔记信息**：
   - 询问用户想要的笔记标题（如果没有明确说明）
   - 建议一个合适的文件名（基于内容主题）
   - 使用 serpapi MCP 搜索一个和和内容相关的封面图片 URL

4. **保存到 Obsidian**：
   - 使用 Obsidian MCP 工具创建或追加笔记
   - 格式化内容为清晰的 Markdown 格式
   - 添加适当的标题、标签、日期等元数据
   - 使用 `mcp__Obsidian__append_content` 创建新笔记

5. **确认结果**：告诉用户笔记已保存，并提供文件路径

## 内容格式建议

保存的内容应遵循以下格式：

```markdown
---
date: [当前日期，格式如：2025-12-18]
cover: [笔记封面图片 URL]
---


# [标题]

## 背景
[简要描述这段内容的背景和来源]

## 内容
[提取的核心内容]

## 相关信息
- 日期：[当前日期，格式如：2025-12-18]
- 来源：Claude Code 对话
```

## 注意事项


- 当前日期使用 `date` 命令获取
- 如果笔记已存在，询问用户是追加还是覆盖
- 保留代码的原始格式和语法高亮标记
- 为重要的概念或决策添加清晰的标题
- 可以根据内容添加适当的标签（如 #todo #idea #solution 等）
