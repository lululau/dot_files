# Directory History Plugin for Yazi

这个插件为 Yazi 文件管理器提供了目录历史功能，允许用户在不同目录之间快速切换。

## 功能特性

- **目录历史记录**: 自动记录用户访问过的目录
- **快速切换**: 在当前目录和上一个目录之间快速切换
- **历史导航**: 访问目录历史记录中的目录
- **多标签支持**: 每个标签都有独立的目录历史

## 键绑定

| 按键 | 功能 | 描述 |
|------|------|------|
| `Alt--` | `plugin dir-hist toggle` | 在当前目录和上一个目录之间切换 |
| `Alt-p` | `plugin dir-hist previous` | 切换到目录历史中的上一个目录 |

## 配置选项

在 `init.lua` 中可以配置以下选项：

```lua
require("dir-hist"):setup {
    history_size = 50,  -- 每个标签保存的目录历史数量，默认50
}
```

## 工作原理

1. **自动记录**: 当用户切换目录时，插件自动将上一个目录添加到历史记录中
2. **去重处理**: 避免重复记录相同的目录路径
3. **大小限制**: 自动限制历史记录大小，防止内存占用过多
4. **标签隔离**: 每个标签都有独立的目录历史，互不干扰

## 使用场景

- 快速在两个相关目录之间切换
- 浏览项目代码时在不同模块目录间跳转
- 文件整理时在源目录和目标目录间切换
- 开发调试时在源码目录和构建目录间切换

## 依赖

- 无需外部依赖
